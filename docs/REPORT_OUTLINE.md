# PDF Report Checklist (maps to the 15 required sections)

1. Cover Page - title, name, reg. no., course (Python Essentials), date
2. Introduction - why expense tracking matters (use statement.md)
3. Problem Statement - from statement.md
4. Functional Requirements - table in ARCHITECTURE.md
5. Non-functional Requirements - table in ARCHITECTURE.md
6. System Architecture - architecture diagram + layer description
7. Design Diagrams - use case, workflow, sequence, class, ER (export from mermaid.live)
8. Design Decisions & Rationale - section in ARCHITECTURE.md
9. Implementation Details - describe each module and key Python concepts used (dataclasses, exceptions, file I/O, comprehensions, argparse)
10. Screenshots / Results - terminal screenshots of add, list, budget status, summary, export
11. Testing Approach - unittest; paste test run output; list edge cases
12. Challenges Faced - e.g. atomic saves, date validation, budget threshold logic, corrupt files
13. Learnings & Key Takeaways
14. Future Enhancements - recurring expenses, charts (matplotlib), SQLite, multi-currency, CSV import
15. References - Python docs (argparse, json, unittest, dataclasses)
